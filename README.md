# 🔒 Gerador de Senhas Seguras em Python

Projeto simples e funcional desenvolvido em Python para gerar senhas aleatórias e personalizadas via terminal. Desenvolvido para colocar em prática conceitos de lógica de programação, manipulação de listas e estruturas condicionais.

---

## 🛠️ Funcionalidades

- **Tamanho personalizado:** Permite escolher senhas entre 9 e 15 caracteres.
- **Caracteres especiais:** Opção de incluir ou não símbolos na senha.
- **Tratamento de entradas:** Validação para evitar respostas inválidas ou fora do limite de tamanho.
- **Saída limpa:** Formatação do resultado final em texto contínuo sem colchetes ou vírgulas.

---

## 🧠 Conceitos e Tecnologias Utilizadas

- **Python 3**
- Importação de módulos nativos (`random`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Manipulação e concatenação de listas
- Métodos de string (`.strip()`, `.lower()`, `.join()`, `.format()`)
